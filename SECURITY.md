# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose credentials, private paths, or unsafe scanner behavior.

Report security concerns privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version, a minimal reproduction, impact, and any suggested mitigation.

Do not include real credentials or private workspace contents. Use synthetic fixtures and redact local paths.

## Supported versions

During the alpha phase, only the latest published version receives security fixes.

## Scope boundary

Agent Safety Doctor is a first-pass operational scanner. It is not a penetration test, compliance certification, or guarantee that an agent setup is safe.
